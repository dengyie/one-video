# 动效规则

动效是为了让信息按旁白的顺序出现，并让画面一直在“往前走”。目标是剪辑感，不是翻页 PPT。

## 节奏

- **每 2–4 秒画面上要有新东西**：一个 cue 揭示、一次机位变化（`shots`）、一个叠层或关键词。`onevideo validate` 的 rhythm 门控在编译后的时间轴上找超过 `gates.maxStill`（默认 4.5s）的空档并给出警告；片尾来源页不算。几乎不动的机位不算新东西：非硬切、zoom 变化 <0.05、x/y 变化 <0.03、旋转 <1° 的 shot 只是漂移。有镜头轨（`shots`）的场景，编译器会给超过这个时长的空档每 ≤3 秒补一次慢推（zoom ±6%，超过 1.2× 改为拉远）：手写镜头优先，正在运动的镜头走完才补，会让下一个手写推镜变得看不出来的那次不补。剩下的告警多出在没有镜头轨的场景，要靠 cue 或叠层来补。
- **跟着声音走**：每个新元素在旁白念到它的那一刻出现。用 `cues` 绑定短语，例如 `"y2026": "排在第一"`；需要提前一点就用 `{ "phrase": "36年后", "offset": -0.4 }`。
- **开场 2.5 秒内亮出主题**：第一个场景是文字主导（kinetic、title 等）时，主标题、数字或贴纸要在 2.5 秒内出现，不要让观众对着一张压暗的背景图等旁白说到关键词。opening 门控在编译后检查（`gates.hookReveal`，设为 0 关闭）：cue 钉在更早的词上，或者用实拍开场。场景有 header、开场就是实拍或图片类场景、或有没写 cue 的元素（会立即出现）时不报。
- **砸字独占画面**：`slam` 关键词是这一刻唯一要读的东西，前几句留下的无时长贴纸在它落下时由编译器收走（写了 `duration` 的按作者的来）。
- **每句一个关键词**：钩子和结论段用 `word` 叠层（`style: slam`）把这句话的数字或判断砸出来，配合 `shots` 的推近或硬切。
- **切点落在重拍上**：有音乐时写 `music.offset: "auto"`。编译器会移动音乐起点，让场景边界、硬切和 slam 关键词尽量压在小节重拍上；切点本身跟着旁白，不会动。镜头和画布停靠点另外会吸附到附近的拍点（见 scene-catalog 的“卡点”）。
- **停留**：最后一个元素出现后至少停 1.5s 再切走（`hold` 或靠旁白尾音）。

## 镜头

- **每个场景都给镜头轨**：`shots: "auto"`（每句字幕一个机位，推/切交替）是底线；关键场景手写 `[{at, zoom, x, y, cut, ease}]`，在 cue 上推近或硬切到细节。同一场景里推近和硬切交替使用。
- **幅度**：推近一次 zoom 变化 0.08–0.2；超过 1.3 的推近要么是硬切，要么给 ≥1s 的 `ease`。
- **实拍做主角**：有实拍素材的段落优先用 `footage`（变速 `ramp`：慢放 0.6–0.7 看清主体，在关键词处提到 1.3 以上），数字用 `word` 叠在旁边，而不是切到一张数据卡。
- **数据要连续**：连续几个数字放在同一个 `canvas` 里，用 `path` 让镜头在卡片之间飞，用 `morph` 让数字变成柱子，下一场景 `inherit: true` 接着飞。不要一张卡一页。
- **背景**：静止的前景下面要有慢速运动（backdrop 的 motion、画布 floor 视差、glow 漂移），否则 QC 会判为冻结。

## 转场

- **按语义选**：实拍接画布、或者要“钻进”一个细节，用 `through`（自动冲向上一镜的深度主体）；话题急转、节奏加快用 `whip`；章节开始用 `wipe` / `iris` / `zoom`；同一话题内的小切换用 `cut` 或短 `fade`。
- 连续 3 个相同转场会被 rhythm 门控警告（`gates.maxSameTransitionRun`，默认 2）。

## 文字与画面

- **深度图先行**：素材到位后跑 `onevideo depth`（`onevideo build` 会在有 depth 工具时自动跑）。有深度图和亮度网格时，编译器会自动完成三件事：
  - 没写 `x` 的 `word` 会避开主体（依次试 0.5 / 0.3 / 0.7）；
  - 文字背后对比度不足 4.5:1 时自动加 `scrim`（浅色字配暗底，深色字配亮底）；
  - 主体挡住字幕带超过 25% 时，这一行字幕移到画面顶部；背景（非 footage/parallax）压暗 ≥0.75 或模糊 ≥4 时主体已看不清，字幕留在底部，避免场景间上下跳。
- 想固定位置就写 `x`；想关掉底就写 `scrim: 0`。
- 两个 `word` 时间重叠且位置相交时，先出现的那个在后一个落下时离场；不想这样就错开 `y`。
- 标题压在主体后面（`footage.title.behind`）需要深度图。

## 运动

- **一次只动一类东西**：柱子在长的时候，标签和标题不要同时飞。
- **进场 0.4–0.7s**，用 easeOut；**退场更快**。风格的 `motion.pace`（slow / medium / fast = 1.35 / 1 / 0.7）统一缩放默认节奏。
- **数字**：没有 `from` 的 stat 逐位翻牌落定；有 `from` 的计数动画不超过 1.2s，最后 20% 放慢。
- **排名交换**：bar-race 的交换要短（≤1.6s），之后停住，让观众读清楚。
- **声音跟着运动**：`sfx.motion: "auto"` 让飞行、硬切、推近、变速自己出声；`captions.style: "kinetic"` 让字幕跟着念到的字动。

## 版面

- 布局单位 `u` = 短边 / 1080，所有尺寸都用 `u` 写，同一份 storyboard 可以输出 16:9 / 9:16 / 1:1。
- 一屏的文字：标题 ≤16 字，卡片标签 ≤8 字，图表系列名 ≤6 字，关键词 ≤6 字。
- 颜色：主色 accent 标重点，其余用 palette；涨用 positive、跌用 negative，不要反着用。

## 反模式

- 一个场景一张静态卡，靠淡入淡出换页。
- 标题或图表停在画面上超过 5 秒，镜头不动、没有新元素。
- 所有元素同时淡入；所有转场都是 fade。
- 弹跳、旋转、3D 翻转之类与内容无关的动效。
- 动画在旁白念到之前就播完了，或者在念完很久之后才出现。

完整示范：`onevideo init demo --example spacex-motion`（实拍变速、主体后标题、画布飞行、through/whip 转场、配乐对齐重拍、关键词避让）。
