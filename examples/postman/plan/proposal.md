# 山中邮差 · tableau 内陆示例

约 40 秒的虚构小故事，示范 `tableau` 的内陆世界：层叠山脊（`hills`，远处积雪、近处更深）、山谷雾（`fog`）、亮窗的小镇（`town`）、树林（`trees`）、飞鸟（`birds`）和大雪（`snow`）。五个场景用 `inherit` 接着上一场的状态演，配 story 叙事配乐。

## 问题链

这是一个什么样的地方？→ 谁走这条路？→ 然后发生了什么？→ 镇上的人做了什么？→ 后来呢？

## 这份分镜示范的写法

- **人走在山梁上**：邮差写 `on: "hills", anchor: "ridge"`（最近的一道山脊；`ridge0` 是最远的一道），只给 x。编译器把他立在那道山脊的脊线上、深度取那道山脊的深度；他沿 `to` 往前走时，每一帧的 y 都跟着脊线起伏，不手算坐标。
- **镜头看人、看镇子**：`on: "postman"`、`on: "town"`，镜头穿过视差解出位置。
- **灯是故事的一部分**：小镇的 `lit` 从 0 推到 1，窗户按固定顺序一扇扇亮；邮差的马灯 `lantern` 在大雪里降到 0.25。
- **天色跟着情绪走**：dusk → night → storm（雪）→ dawn；白天山脊不再描亮边（rim 随天空亮度自动减弱）。
