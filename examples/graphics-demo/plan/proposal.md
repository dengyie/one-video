# 提案：光有多快 · 纯代码示例

- **角度**：用一个所有人都听过、却很少有人算过的数字——光速——走一趟从地球到太阳的尺度，演示 graphics 流水线：每一帧都由代码绘制，没有照片、实拍、截图或生成素材。
- **受众**：对科学感兴趣的中文观众，无需物理背景。
- **长度**：约 36 秒，16:9，风格 vector-flow，3 章节（光速 / 尺度 / 时间）。
- **问题链**：光一秒跑多远？→ 这有多远（绕地球几圈）？→ 月亮、太阳有多远？→ 光要走多久？→ 所以我们看到的太阳是什么时候的？
- **画面**：动态排字（particles 背景）→ 旋转地球仪 → 嵌套圆对数缩放（waves 背景）→ 无限画布上两个计时数字 → 结论排字（aurora 背景）→ 来源。
- **声音**：程序化音乐 pulse、程序化转场与运动音效、TTS 旁白。
- **数据纪律**：光速为 SI 定义值（BIPM），距离取 NASA 行星数据表的轨道半长轴；周长、圈数和光行时间是由这些数推算的，research 中标为 estimate 并写明算式。
